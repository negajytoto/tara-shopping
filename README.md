# 타라 X배너 상세페이지 - 실제 이미지 적용 버전

사용자가 제공한 ZIP 파일에서 실제 이미지를 확인해 적용했습니다.

적용한 이미지:
- 실내용배너.zip / 미니배너.jpg → 메인 이미지와 사이즈 안내
- 실내용배너.zip / 퀵배너_A.jpg, 퀵배너_B.jpg → 갤러리
- 소재.zip / 패트(UV).jpg, 투명필름(비점착).jpg, 스트립메쉬.jpg → 소재 안내

구성품·설치 과정·설치 사례는 해당 실제 사진이 아직 없어서 임시 영역을 유지했습니다.
사진을 추가로 제공하면 같은 방식으로 교체할 수 있습니다.

하단 타라 로고는 색상 필터 없이 원본 파일을 사용합니다.
