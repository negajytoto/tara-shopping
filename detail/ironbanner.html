IRON BANNER
철제배너-PY
견고한 철제 프레임과 물통 베이스를 사용하는 스프링 철제배너입니다. 소형·중형·대형 3가지 규격으로 선택할 수 있습니다.
USE CASE
다양한 공간에서 활용
매장 앞 홍보부터 야외 이벤트, 전시회, 안내 공간, 식당과 카페까지 다양한 공간에 활용할 수 있습니다.
MATERIAL GUIDE
출력 소재 안내
설치 환경과 표현 방식에 맞춰 매쉬, 투명, 패트 UV 소재를 선택할 수 있습니다.
매쉬
미세한 망사 구조로 바람이 잘 통하여 야외 설치에 적합한 소재입니다.
투명
배경이 비치는 투명 소재로 깔끔하고 개방감 있는 연출에 적합합니다.
패트 UV
탄탄한 패트 소재에 UV 방식으로 출력하여 선명한 표현이 가능합니다.
SIZE GUIDE
사이즈 안내
실제 거치대 규격을 기준으로 소형 5012, 중형 5015, 대형 6018을 비교해 주세요.
PRODUCT GUIDE
거치대 구성품
프레임과 베이스 연결 부품, 높이조절발, 출력물 고정 스프링걸이 등 거치대의 주요 구성품을 확인해 주세요.
WATER BASE GUIDE
스프링 배너 물통
소형·중형에는 18L, 대형에는 25L 물통을 사용합니다. 물을 채우면 하단 무게가 확보되어 보다 안정적으로 설치할 수 있습니다.
INSTALLATION GUIDE
거치대 조립 방법
하단 프레임과 베이스를 연결하고 상단 프레임을 조립한 뒤 높이조절발과 스프링걸이를 이용해 설치합니다.
REAL PRINTING GUIDE
실사출력 작업 안내
출력 접수 전 색상모드, 작업 사이즈, 폰트 아웃라인과 이미지 상태를 확인해 주세요.
색상 모드CMYK 모드로 작업
작업 사이즈주문 사이즈 기준 1:1 작업
폰트모든 폰트 아웃라인 처리
최종 확인오탈자, 이미지 해상도, 작업 사이즈 및 출력물 위치 확인
