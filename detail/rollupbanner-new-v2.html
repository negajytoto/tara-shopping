WHY ROLL-UP

펼치는 순간 완성되는 홍보 공간

01

빠른 설치

출력물을 위로 당기고 지지대에 고정하면 설치가 끝납니다.

02

본체 수납

사용 후 출력물이 본체 안으로 말려 들어가 깔끔하게 보관됩니다.

03

간편한 이동

전용 케이스에 넣어 행사장과 매장 사이를 편리하게 이동할 수 있습니다.

04

실내용 안내

전시·행사·매장 입구와 기업 안내 공간에 적합합니다.

INSTALLATION

빠르고 간단한 설치 방법

본체를 놓고 지지대를 연결한 뒤 출력물을 천천히 올려 고정합니다.

SCREEN CHANGE

배너 화면 교체 방법

내부 스프링이 풀리지 않도록 화면을 안전핀으로 고정한 뒤 기존 화면을 분리하고 새 화면을 연결합니다.

교체 전 주의
안전핀을 먼저 체결하지 않으면 화면이 본체 안으로 빠르게 감길 수 있습니다. 제품별 연결 방식이 다를 수 있으므로 결합 구조를 확인하고, 교체가 어려운 경우 전문 작업을 권장합니다.

FILE GUIDE

작업 파일을 확인해 주세요

주문 규격으로 작업

선택한 출력 사이즈와 동일한 가로·세로 규격으로 제작해 주세요.

하단 여유 확인

본체 결합부에 들어가는 하단 영역에는 중요한 문구와 로고를 배치하지 마세요.

출력 데이터 점검

이미지 해상도, CMYK 색상, 글자 윤곽선과 연결 이미지 누락을 확인해 주세요.

사용 시 주의사항
출력물을 놓을 때는 손으로 잡은 상태에서 천천히 수납해 주세요. 급하게 놓으면 출력물과 내부 스프링이 손상될 수 있으며, 강한 바람이 부는 실외 사용은 권장하지 않습니다.
