USE CASE
다양한 공간에서 돋보이는 활용법
매장 앞, 전시회와 행사, 야외 이벤트, 세일·프로모션, 안내 공간 등에서 활용할 수 있습니다.
SIZE GUIDE
사이즈 안내
단면형과 양면형의 출력 크기 및 제품 구성을 확인해 주세요. 실제 주문 시 선택 가능한 규격을 기준으로 작업합니다.
TYPE GUIDE
단면형 · 양면형 안내
전면 한 면을 사용하는 단면형과 앞·뒤 두 면을 활용하는 양면형 구조를 비교해 확인해 주세요.
MATERIAL GUIDE
출력 소재 안내
설치 환경과 표현 목적에 맞춰 출력 소재를 선택해 주세요. 아래 구성은 참고하신 소재 종류를 타라 상세페이지 스타일로 새롭게 정리했습니다.
소싱페트
표면이 매끄럽고 색 표현이 선명한 소재로, 일반적인 배너 홍보물에 활용하기 좋습니다.
UV배너
UV 출력에 적합한 배너 소재로 선명한 색 표현과 실외 홍보용 활용을 고려할 수 있습니다.
매쉬천
미세한 타공 구조로 바람의 영향을 줄이는 데 유리해 실외 배너에 활용하기 좋습니다.
펄반사지
빛을 받았을 때 반사 효과가 돋보이는 소재로 야간 시인성이 필요한 안내물에 활용할 수 있습니다.
투명필름(UV)
투명한 필름 계열 소재로 유리면·투명 표현이 필요한 그래픽에 활용할 수 있습니다.
벌집반사지
반사 구조가 강조되는 소재로 야간 안내·안전 목적의 시인성 확보가 필요한 경우 활용할 수 있습니다.
※ 실제 주문 가능 소재와 출력 방식은 상품 주문 옵션을 기준으로 확인해 주세요. 모니터 환경에 따라 실제 출력 색상과 차이가 있을 수 있습니다.
INSTALL GUIDE
설치 방법
물통 베이스를 안정적으로 준비한 후 폴대를 조립하고 출력물의 상·하단 고리를 프레임과 베이스에 체결합니다.
REAL PRINTING GUIDE
실사출력 작업 방법
정확하고 선명한 출력을 위해 색상 모드, 해상도, 작업 사이즈, 폰트, 파일 형식과 이미지 상태를 확인해 주세요.
