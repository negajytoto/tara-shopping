PRODUCT FEATURE
설치부터 보관까지 간편한 롤업 구조
배너가 본체 안으로 말려 들어가는 구조로 이동과 보관이 편리하며, 행사장과 매장에서 빠르게 설치할 수 있습니다.
USE CASE
다양한 공간에서 돋보이는 활용법
카페, 매장, 병원, 전시회, 이벤트와 사무실 등 반복 설치와 이동이 필요한 공간에 적합합니다.
MATERIAL GUIDE
출력 소재 안내
표현 방식과 사용 기간에 따라 PET, 유포지, 합성지 등의 소재를 선택할 수 있으며 실제 제공 소재는 주문 옵션을 기준으로 합니다.
SIZE GUIDE
공간과 메시지에 맞는 사이즈 선택
좁은 통로부터 전시장과 행사장까지 설치 환경에 맞는 규격을 선택하세요. 최종 제작 규격은 주문 화면의 옵션을 확인해 주세요.
INSTALLATION
빠르고 간단한 설치 방법
본체를 바닥에 놓고 배너를 위로 당긴 뒤 지지봉과 상단바를 연결하면 설치가 완료됩니다.
FILE GUIDE
실사출력 파일 작업 안내
색상 모드 CMYK 모드 권장
작업 크기 실제 크기 1:1, 인쇄 여분 없음
글꼴 윤곽선 처리 후 저장
대지 위치 Illustrator 대지 X, Y 좌표 0, 0 확인
대용량 파일 효과와 개체가 많으면 JPG 또는 PDF로 정리
작업 전 확인: 접수된 데이터는 별도 수정 없이 출력될 수 있으므로 미리보기, 폰트 아웃라인, 링크 이미지 포함 여부와 대지 원점을 확인해 주세요.
FAQ
자주 묻는 질문
실외에서도 사용할 수 있나요?
롤업배너는 기본적으로 실내용을 권장합니다. 바람이나 비를 맞는 환경은 피해주세요.
출력물만 교체할 수 있나요?
거치대 구조와 출력물 연결 방식에 따라 교체 가능 여부가 달라질 수 있으므로 주문 옵션을 확인해 주세요.
전용 가방이 포함되나요?
구성품 포함 여부는 선택한 상품 옵션을 기준으로 확인해 주세요.
